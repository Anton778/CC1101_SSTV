Научная рота. Пульт радиосвязи ESP32 / ESP32-S3 N16R8 + CC1101. SSTV Robot 36.

Содержимое:
  SSTV_Robot36_DDS.ino  - настройки и учебный цикл поиска частоты
  image_data.h          - исходный файл изображения, НЕ изменён
  src/SstvRadio.h       - названия режимов и функции станции
  src/SstvRadio.cpp     - управление CC1101 и измерение RSSI
  src/Robot36Tx.*       - заголовок VIS, строки изображения и генератор DDS
  src/StationCommands.* - разбор команд монитора порта
  src/RxCapture.*       - запись демодулированного сигнала через USB
  src/ImageStore.*      - проверка и сохранение картинок, полученных по USB
  tools/station/        - общий пульт, переключение RX/TX, приём, поиск, чат, опыт со свипом
  src/BoardProfile.h    - разводка двух типов плат
  src/PacketChat.*      - передача текста по CC1101 и сборка сообщений
  tools/sender/         - очередь изображений и отправка через USB без перепрошивки
  tools/receiver/        - браузерный конвертер записи в PNG и опыт со свипом

Переименовать распакованную папку в SSTV_Robot36_DDS и открыть в ней SSTV_Robot36_DDS.ino.
Скетч, image_data.h и папку src хранить вместе. Полная инструкция приведена в README.md.
Платы: ESP32 Dev Module и ESP32S3 Dev Module (N16R8).
Для S3 выбрать Flash Size 16MB, OPI PSRAM, Default 4MB with spiffs. Для USB–UART отключить USB CDC On Boot.
Для штатного USB S3 выбрать Hardware CDC and JTAG и включить USB CDC On Boot.
Установить библиотеку RadioLib 8.0.0.
Монитор порта: 115200 бод.

Для соревнований один раз загрузить текущий скетч в ESP32 (стандартная разметка 4 МБ с spiffs).
Закрыть монитор порта и открыть tools/station/index.html из распакованной папки в Chrome или Edge.
Нажать «Подключить плату», выбрать порт и перетащить одну или несколько картинок.
Каждая получит полный кадр Robot 36 (36,91 с). Оставить окно открытым до конца очереди.
В режиме TX последняя сохранённая картинка повторяется и после отключения компьютера.
До первой USB-загрузки плата передаёт встроенный image_data.h.

Распиновка сохранена:
 CC1101   ESP32
 VCC      3V3 (НЕ 5V)
 GND      GND
 SCK      GPIO18
 MISO     GPIO19
 MOSI     GPIO23
 CSN      GPIO21
 GDO0     GPIO4
 GDO2     GPIO27

Для ESP32-S3: SCK=12, MISO=13, MOSI=11, CSN=21, GDO0=4, GDO2=5, питание 3V3.
Радиочат: на обеих станциях выбрать один канал и включить чат. По умолчанию 433.500 МГц.
Для приёма SSTV в общем пульте нажать «Принять и декодировать». WAV и PNG можно сохранить.
Во вкладке поиска задать начало/конец, шаг и порог RSSI. Опыт со свипом выполняется в звуковой записи.

Частота несущей 433.920 МГц; мощность первоначально 0 dBm (для SDR рядом).
При штатных настройках подача питания запускает повторяющуюся передачу Robot 36.
В мониторе порта выберите 115200 бод и окончание строки NL или CR+LF.
  RX                 - перейти на приём
  RX 433.920         - выбрать канал приёма в МГц
  TX                 - вернуться на передачу
  Stop SSTV          - прервать кадр и остановить повторы (также Stop_SSTV)
  Start_SSTV         - запустить повторы с заголовка VIS в режиме TX
  SCAN 433720 434120 -75 25 - один проход в RX: начало и конец в кГц, порог в дБм, шаг в кГц
  SCAN               - один проход с настройками скетча
  STATUS, HELP       - текущее состояние, список команд
После Stop SSTV повторы включаются командой Start_SSTV или при следующей подаче питания.
После прохода приёмник возвращается на прежний канал. Уровень выше порога отмечен словом СИГНАЛ.
Для записи закройте монитор и откройте tools/receiver/index.html из распакованного проекта
в настольном Chrome или Edge. Выберите порт приёмной платы, сохраните WAV и декодируйте PNG.
В браузере команда WAV_SWEEP 1100 2300 -6 2 создаёт копию WAV со звуковым свипом
1100–2300 Гц при уровне −6 дБ относительно мощности записи и полном периоде 2 с.
Полный порядок настройки и задания приведены в README.md.
SDR: NFM, полоса 12-15 кГц, шумоподавитель выключен, аудио -> Robot 36.
Перед каждым изображением автоматически идёт заголовок VIS=8.

Что изменено относительно предыдущей версии:
 - вместо многократного ledcChangeFrequency: DDS на аппаратном таймере 80 кГц;
 - на границах пикселей изменяется частота, но НЕ обнуляется фаза меандра;
 - используются те же длительности строк (150 мс) и цветоразностные сигналы;
 - исходный RGB565-файл не редактируется;
 - ведётся диагностика опозданий по временным границам.

Сборка проверена для обеих плат с Arduino-ESP32 3.1.3, 3.3.12 и 4.0.0 и библиотекой RadioLib 8.0.0.
При ошибке «esp_jpg_decode.h: No such file or directory» заменить src/ImageStore.cpp файлом из текущей версии проекта.
Передавать только в разрешённых условиях и с подключённой антенной.
