Приём и декодирование

Научная рота · Общий пульт радиосвязи

Отправка SSTV

Подключите передатчик по USB и добавьте картинки. Плата передаст их по очереди в режиме Robot 36.

Плата отключена

Перед подключением закройте монитор порта Arduino IDE.

Изображения

PNG, JPEG, WebP и BMP. Картинка целиком вписывается в кадр 320 × 240. По краям при необходимости добавляются белые поля.

Очередь передачи

Очередь пуста. Можно добавить сразу несколько файлов.

    Кадр занимает 36,91 с в эфире. После завершения очереди плата повторяет последнюю картинку, в том числе при автономном питании в режиме TX.
